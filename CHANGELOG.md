# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

The patch number is bumped automatically by `installer/build-msi.ps1` whenever the add-on
sources or the WiX definition change, and the current number is kept in
[`installer/version.txt`](installer/version.txt).

## [Unreleased]

### Added

- **MSI code signing.** `installer/build-msi.ps1` accepts `-PfxPath`/`-PfxPassword` or
  `-Thumbprint` (plus `-TimestampUrl`), runs `signtool sign` with an RFC 3161 timestamp and then
  `signtool verify /pa`. An unsigned build now warns instead of letting the user meet SmartScreen
  unprepared.
- `server_status` reports `logPath` — the log file actually in use, primary or fallback.
- `SECURITY.md`, `CONTRIBUTING.md`, issue forms and a pull-request template under `.github/`.
- `docs/check-docs.ps1`, run in CI, to keep the two READMEs in step and stop duplicated tables and
  hard-coded tool counts from drifting.
- **Bilingual MSI.** `installer/Strings.en-US.wxl` and `Strings.ru-RU.wxl` carry every user-visible
  string, `installer/EULA.ru.rtf` carries the Russian licence, and `build-msi.ps1 -Culture` builds
  one package per language (`CorelMcpAddon-27.msi`, `CorelMcpAddon-27-ru.msi`). The upgrade dialog
  used to be Russian inside an otherwise English package.
- **Add/Remove Programs identity.** Publisher is `pefedotov` instead of repeating the product name,
  and the entry now has an icon (`installer/app.ico`, regenerated by `installer/make-icon.ps1`),
  a *Support* link, an *About* URL and a *Comments* line.
- The docker panel names the endpoint in plain words, shows the status in colour, and has a
  **Docs** button. Failures from the Tools list and from Copy config now raise a message box
  instead of disappearing into the log pane.

### Changed

- **README rewritten around the user, not the architecture** (both languages): what can be asked
  for, a 60-second quick start, "will this work for me", separate paths for designers and
  developers, a troubleshooting table. The toolbox checklist and the tool group list moved to
  `docs/` as their single source of truth; the hard-coded tool count is gone from prose.
- `docs/installing.md` gained a "what you will see before the installer starts" section
  (SmartScreen and UAC) and now documents the log location as primary path plus fallback.
- `docs/client-config.md` owns the `config.json` table (with `DisabledTools` and a working
  `AllowedRoots`) and the full tool list.
- `docs/tools.md` is bilingual — English text, toolbox names in both UI languages — since the
  English README points at it as the canonical coverage list.
- The MCP server names itself `coreldraw_mcp` in `serverInfo.name`, matching the repository and the
  install folder (it was `coreldraw-mcp`).
- **Tool and parameter descriptions say more.** 13 tools had a description under 40 characters
  ("Remove the outline."), and 59 parameters were one to three words ("Top edge."). Coordinates now
  name their unit and their axis, indices say 1-based on the layer, and levels give their range —
  a client's model sees nothing but these strings.

### Fixed

- Documentation stated the log lived in `%LOCALAPPDATA%\CorelMcp\`, which is only the fallback used
  when the add-on folder is not writable.
- Failure messages a client actually sees now say what to do: `404` names `/mcp` and `/health`,
  `401` names `AuthToken`, `405` says POST, an unknown tool says to call `tools/list`, a disabled
  tool points at the **Tools** button.
- `docs/installing.md` said "two ways to deploy" above a table of three.

## [1.0.29] - 2026-10-17

Initial public release. Versions 1.0.0–1.0.28 were private iterations before publication; they
were never tagged or released.

### Added

- **In-process MCP server** for CorelDRAW Graphics Suite, hosted inside `CorelDRAW.exe` and
  reachable over MCP Streamable HTTP on loopback (`http://127.0.0.1:8765/mcp`).
- **106 tools** covering the CorelDRAW toolbox: documents and pages, layers and guides,
  drawing primitives and curves, text, dimensions and connectors, fill and outline, colour,
  interactive effects, object composition, and export. (106 was the count at that release;
  `tools/list` and `server_status` are authoritative.)
- **Docker panel** (*CorelDRAW MCP Server*) with Start/Stop and a **Tools** button that hides
  tools from `tools/list` live, stored in `config.json` as `DisabledTools`.
- **MSI package** for CorelDRAW 2025 (26) and 2026 (27), with per-version product identity so
  both releases install side by side, automatic version bump, and a `config.json` that
  survives upgrade and uninstall.
- **`addon/` build output** — the ready-to-copy payload for a manual install into
  `Programs64\Addons\CorelMcp`.
- **Documentation**: [`README.md`](README.md) / [`README.ru.md`](README.ru.md),
  [`docs/installing.md`](docs/installing.md),
  [`docs/client-config.md`](docs/client-config.md),
  [`docs/tools.md`](docs/tools.md) (toolbox coverage checklist).

### Security

- The endpoint binds `127.0.0.1` only and is not intended to be exposed. `AuthToken` and
  `AllowedRoots` are available for restricted setups.
