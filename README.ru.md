# Надстройка CorelDRAW MCP

**English version: [README.md](README.md)**

[![build](../../actions/workflows/ci.yml/badge.svg)](../../actions/workflows/ci.yml)

Попросите ИИ-агента нарисовать — и он нарисует в том документе CorelDRAW, который у вас открыт.
Надстройка превращает запущенный CorelDRAW Graphics Suite в **MCP-сервер** (Model Context
Protocol), поэтому MiMoCode, Claude Desktop, Cursor, OpenCode и любой другой MCP-клиент работает
с настоящей объектной моделью: фигуры, текст, заливки, абрисы, эффекты, слои, страницы и экспорт.

```
MCP-клиент  ──HTTP(петлевой интерфейс)──▶  CorelDRAW.exe (аддон)  ──VGCore COM──▶  рисунок
                  http://127.0.0.1:8765/mcp
```

## Что можно попросить

Когда агент подключён, достаточно запроса — инструменты он выберет сам:

> Сделай флаер A6: прямоугольник 148 × 105 мм с золотой градиентной заливкой, заголовок
> «Autumn Sale» фигурным текстом 36 pt сверху, и экспортируй PNG 200 dpi рядом с документом.

> Свари три выделенные фигуры, дай результату абрис 2 мм цветом #C9A227 и сгруппируй с логотипом.

> На всех страницах документа замени текст «2025» на «2026» и переведи заголовки в кривые.

Всё происходит в открытом документе и попадает в собственную историю отмен CorelDRAW: надстройка
управляет объектной моделью приложения, а не имитирует щелчки мышью.

## Быстрый старт (60 секунд)

1. **Установите надстройку.** Скачайте `CorelMcpAddon-27.msi` (CorelDRAW 2026) или
   `CorelMcpAddon-26.msi` (CorelDRAW 2025) со страницы [Releases](../../releases/latest) и запустите;
   сборка с суффиксом `-ru` показывает русские диалоги.
   Windows спросит дважды — SmartScreen («Подробнее → Выполнить в любом случае», для пакета без
   известного издателя) и UAC (аддон ставится для всех пользователей). Оба вопроса ожидаемы;
   подробности — в [`docs/installing.md`](docs/installing.md#what-you-will-see-before-the-installer-starts).
   Готового пакета ещё нет или хотите собрать сами? См. [Сборка](#сборка).
2. **Запустите CorelDRAW** и откройте **Окно ▸ Докеры ▸ Corel MCP** (или
   **Инструменты ▸ Corel MCP**). «Докер» — название закрепляемой панели в CorelDRAW, к контейнерам
   Docker отношения не имеет. Панель должна показать `running`: именно её открытие запускает
   сервер.
3. **Подключите агент к эндпоинту.** Большинству клиентов нужен только URL:

   ```json
   {
     "mcpServers": {
       "coreldraw": { "url": "http://127.0.0.1:8765/mcp" }
     }
   }
   ```

   Готовые блоки для Claude Desktop, Cursor, MiMoCode, OpenCode и любого Streamable-HTTP клиента —
   в [`docs/client-config.md`](docs/client-config.md).
4. **Попросите рисунок.**

Эндпоинт — `http://127.0.0.1:8765/mcp`; `GET /health` отвечает `ok`. Если ничего не подключается,
журнал покажет, где всё остановилось, — см. [Если что-то не работает](#если-что-то-не-работает).

## Подойдёт ли мне?

| | |
|---|---|
| Приложение | CorelDRAW Graphics Suite **2025 (26)** или **2026 (27)** |
| ОС | Windows |
| Права | администратор для установки — аддон лежит в `Program Files` |
| Клиент | любой, кто умеет MCP Streamable HTTP, либо мост stdio |

**Не заработает, если:**

- ваш CorelDRAW старше 2025 — у этих двух выпусков разные сборки interop, и надстройка собрана
  именно под них;
- вы на macOS или в веб-версии;
- нет прав администратора и нельзя писать в `Program Files`: пользовательской папки для аддонов
  CorelDRAW не сканирует (`%APPDATA%`, `%LOCALAPPDATA%`, `%ProgramData%` не читаются);
- у вашего MCP-клиента нет ни HTTP-транспорта, ни моста stdio.

## Выберите свой путь

**Дизайнеру** — короткая версия уже есть в разделе [Что можно попросить](#что-можно-попросить).
Что стоит знать до того, как доверить агенту реальный файл:

- ИИ-агент работает с документом, открытым в CorelDRAW; несохранённая работа рискует ровно так же, как
  если бы вы двигали фигуры мышью. `Ctrl+Z` отменяет его правки, как любые другие.
- Инструменты адресуют фигуры по *номеру с 1 на активном слое*, по *имени* или по *текущему
  выделению*. После вызова, вставляющего фигуру (например, тени), номера сдвигаются — попросите
  агента перечитать `list_shapes`.
- Новые примитивы сохраняют абрис CorelDRAW по умолчанию. Если нужна чистая заливка, попросите
  «без абриса».
- 22 инструмента тулбокса вообще нельзя вызвать программно: нож, ластик, сетчатая заливка, умное
  рисование и другие работают только мышью. Полный список с причинами —
  в [`docs/tools.md`](docs/tools.md).
- Кнопка **Tools** в панели позволяет снять галочку с любого инструмента, к которому агент не
  должен прикасаться. Выбор применяется сразу и переживает перезапуск.
- Эндпоинт слушает только эту машину (`127.0.0.1`) и из сети недоступен.

**Разработчику** — надстройка это одна сборка `net48`, загружаемая в `CorelDRAW.exe`; протокол MCP
и слой JSON встроены, поэтому сторонних зависимостей времени выполнения нет. Транспорт —
Streamable HTTP поверх JSON-RPC 2.0. Разделы ниже: [Инструменты](#инструменты),
[Структура репозитория](#структура-репозитория), [Сборка](#сборка),
[Особенности поведения](#особенности-поведения), [Безопасность](#безопасность).

## Инструменты

Источник истины — `tools/list`: спросите агента или вызовите `server_status` (он отдаёт `toolCount`
и `enabledToolCount`). Группы возможностей:

| Группа | Что покрывает |
|---|---|
| документы и страницы | создать / открыть / сохранить / закрыть, размер, ориентация, единицы, активная страница |
| фигуры | прямоугольник, эллипс, линия, многоугольник, звезда, спираль, сетка, кривые, импорт изображений и SVG |
| текст | фигурный и простой текст, чтение / замена, текст в кривые, по кривой, внутри фигуры |
| цвет и заливка | однородная, градиентная, узорная, текстурная, PostScript; абрис: цвет и толщина; прозрачность |
| преобразования | позиция, размер, масштаб, перемещение, поворот, наклон, дублирование, клонирование, порядок, выравнивание, группа, блокировка |
| выделение | по номеру, по списку номеров, по имени, по типу или всё на слое |
| булевы операции и формовка | объединение, разъединение, сварка, исключение, пересечение, скругление, фаска, выемка |
| эффекты | перетекание, ореол, тень, оболочка, вытягивание, линза, искажение, настройка цвета, сведение |
| символы и PowerClip | в символ и обратно, поместить внутрь, извлечь |
| слои, макет, навигация | слои, направляющие, сетка, масштаб и панорама |
| экспорт | любой поддерживаемый формат плюс `export_pdf` / `export_png` / `export_svg` / `export_dxf` |
| сервер | `server_status`, `server_log` (последние вызовы, аргументы, время) |

Полный список по группам — в [`docs/client-config.md`](docs/client-config.md#tools); чек-лист
покрытия тулбокса, включая 22 пункта, недостижимых через объектную модель, —
в [`docs/tools.md`](docs/tools.md).

## Настройка

`config.json` лежит рядом с `CorelMcp.dll` в `<CorelDRAW>\Programs64\Addons\CorelMcp\`:

| Поле | По умолчанию | Значение |
|---|---|---|
| `Port` | `8765` | TCP-порт точки входа |
| `BindAddress` | `127.0.0.1` | только петлевой интерфейс — не расширяйте его без `AuthToken` |
| `AutoStart` | `true` | запускать сервер при загрузке аддона |
| `AuthToken` | `""` | если задан, запросы должны присылать `Authorization: Bearer <token>` |
| `MaxBodyBytes` | `4194304` | отклонять более крупные тела запросов |
| `AllowedRoots` | `""` | папки, на которые могут указывать аргументы-пути; пусто — без ограничений |
| `DisabledTools` | `""` | имена инструментов: скрываются из `tools/list` и отклоняются `tools/call` |

Кнопка **Tools** правит `DisabledTools` и применяет список к уже запущенному серверу сразу.
Остальные изменения вступают в силу при следующем запуске (переключатель **Stop/Start** или
перезапуск CorelDRAW). Подробности, включая настройку каждого клиента, —
в [`docs/client-config.md`](docs/client-config.md).

## Структура репозитория

```
src/CorelMcpAddon/          сама надстройка
  Addon.cs                  точка входа (хуки аддона CorelDRAW)
  ToolCatalog.cs            сборка реестра инструментов
  Tools/                    по файлу на группу инструментов плюс реестр и построители схем
  Mcp/                      HTTP-сервер (Streamable HTTP), протокол MCP / JSON-RPC 2.0
  Json/                     собственный слой JSON (без сторонних сборок)
  Corel/                    мост к объектной модели VGCore
  Config/                   модель config.json
  Ui/                       закрепляемая панель
src/CorelMcpAddon.Tests/    тесты xUnit — чистые модульные, CorelDRAW не нужен
docs/                       установка, конфигурация клиентов, покрытие тулбокса, проверка доков
installer/                  определение WiX, скрипт сборки и подписи, EULA, version.txt
deploy/install.ps1          развёртывание для разработки
.github/                    CI, политика безопасности, гид для контрибьюторов, формы issue
LICENSE                     MIT
CHANGELOG.md                история версий
```

`addon/` (пять файлов для ручной установки) создаёт сборка **Release**, `dist/` (результат MSI) —
`installer\build-msi.ps1`. В свежем клоне нет ни того, ни другого — см. [Сборка](#сборка).

## Сборка

Нужны .NET SDK, умеющий собирать `net48` (проверено на .NET 10), локально установленный CorelDRAW
с `Corel.Interop.VGCore.dll` и WiX Toolset v5 (подтягивается как локальный инструмент dotnet).

```powershell
dotnet build src\CorelMcpAddon\CorelMcpAddon.csproj -c Release -p:CorelDrawVersion=27
dotnet test  src\CorelMcpAddon.Tests\CorelMcpAddon.Tests.csproj
.\installer\build-msi.ps1                    # -> dist\CorelMcpAddon-27.msi
.\installer\build-msi.ps1 -Thumbprint <hex>  # подписать перед публикацией
```

`CorelDrawVersion` выбирает и сборку interop для компиляции, и папку установки:
`26` — CorelDRAW 2025, `27` — CorelDRAW 2026 (по умолчанию).

Развернуть можно тремя способами — MSI, `deploy\install.ps1` для разработки и простое копирование
папки; все описаны в [`docs/installing.md`](docs/installing.md). Права администратора нужны в любом
случае.

Тесты — обычные xUnit: они проверяют реестр инструментов, слой JSON, слой JSON-RPC/HTTP, модель
конфигурации, преобразование единиц и геометрию построений. Сборка interop должна быть на месте,
чтобы разрешилась ссылка, но сам CorelDRAW запускать не требуется.

CI (`.github/workflows/ci.yml`) выполняет те же команды на **self-hosted Windows-раннере с меткой
`coreldraw`**: ни на одном хостируемом раннере нет `Corel.Interop.VGCore.dll`. Запускается он на
push в `main` и вручную; на pull request выполняется только проверка документации
(`.github/workflows/docs.yml`) на хостируемом раннере, поэтому код форка никогда не попадает на
машину с CorelDRAW. Внешние форки не могут получить зелёную галочку без лицензии CorelDRAW — это
свойство проекта, а не признак сломанной сборки. `build-msi.ps1` поднимает номер патча сам и только
после успешной сборки. Требования и правила участия:
[`CONTRIBUTING.md`](.github/CONTRIBUTING.md).

## Особенности поведения

Полезно знать до того, как писать сценарии под API; обоснования и остальной список —
в [`docs/client-config.md`](docs/client-config.md#tool-behaviour-worth-knowing):

- **Координаты задаются в единицах документа, ось Y направлена вверх от левого нижнего угла
  страницы.** Поле `referencePoint`, которое возвращает `get_document_info`, — это настройка
  отображения линеек, начало координат она не переносит.
- **Примитивы `create_*` сохраняют абрис CorelDRAW по умолчанию.** Для чистой заливки нужен
  `set_outline_none`.
- **Индексы фигур — движущаяся цель.** `drop_shadow` вставляет фигуру группы и сдвигает все нижние
  индексы на единицу, поэтому после любого инструмента, вставляющего фигуру, перечитывайте
  `list_shapes`.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| Нет панели или меню | CorelDRAW кэширует рабочее пространство. Закройте его и запустите, удерживая **F8**, чтобы сбросить (сначала сделайте копию `%AppData%\Corel\…\Workspace`). |
| Ничего не подключается, панель пишет `running` | Проверьте порт: `Port` в `config.json`, затем `GET http://127.0.0.1:8765/health`. |
| `Failed to bind to address` | Порт занят — смените `Port` и перезапустите сервер. |
| Инструмент отвечает «no active document» | Сначала создайте или откройте документ. |
| Всё остальное | Читайте журнал. Он пишется рядом с аддоном (`corelmcp.log`), если папка доступна на запись, а запасной путь — `%LOCALAPPDATA%\CorelMcp\corelmcp.log`; после установки через MSI используется именно он, потому что `Program Files` недоступна непривилегированному CorelDRAW. `server_status` сообщает фактический путь (`logPath`), те же строки видны на панели **Log**. |

Больше случаев, включая проблемы установки: [`docs/client-config.md`](docs/client-config.md#troubleshooting)
и [`docs/installing.md`](docs/installing.md).

## Безопасность

Всё остаётся на этой машине. Точка входа слушает `127.0.0.1` и из сети недоступна; наружу аддон
не обращается ни к какому сервису.

Тот, кто *сможет* до неё дотянуться, получает управление вашим сеансом CorelDRAW с полными
правами приложения — включая чтение и запись файлов через инструменты документов и экспорта.
Значения по умолчанию рассчитаны на то, что машиной пользуетесь только вы: `AuthToken` пуст,
`AllowedRoots` не ограничивает пути.

Если доступ нужен не только с петлевого интерфейса, сделайте все три шага: задайте `AuthToken`,
сузьте `AllowedRoots` и поставьте сервер за туннель, которым управляете вы. Одна смена
`BindAddress` отдаёт управление CorelDRAW на уровне администратора любому в сети. Как сообщить об
уязвимости: [`SECURITY.md`](.github/SECURITY.md).
